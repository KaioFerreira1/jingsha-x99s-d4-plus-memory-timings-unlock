# Contributing

Contributions are welcome, but keep the repository safe and auditable.

## Do Not Submit

- BIOS dumps.
- Ready-to-flash BIOS images.
- AMIBCP binaries.
- Intel FPT / Intel ME System Tools binaries.
- UEFITool binaries.
- Serial numbers, MAC addresses, board UUIDs, or other unique firmware data.

## Useful Contributions

- Reports for the same board with exact BIOS version and hashes.
- Patch notes for other compatible X99 boards.
- Screenshots of AMIBCP and real BIOS Setup validation.
- Stability test results after unlocking memory controls.
- Safer validation scripts.

## Required Information For New Board Reports

Please include:

- Board name printed on PCB.
- CPU model.
- Memory kit model, if known.
- BIOS date/version shown by the board.
- Module hashes before and after patching.
- AMIBCP screenshot showing the hidden menu.
- Real BIOS Setup screenshot if flashed and tested.
- Clear statement whether the board booted after flashing.
