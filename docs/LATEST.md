## Release Policy

GitHub releases for this project should not include BIOS images.

Allowed release assets:

- Source code archive generated by GitHub.
- Documentation.
- Scripts.
- Checksums for module bodies.

Not allowed release assets:

- Full SPI dumps.
- BIOS region dumps.
- Modified BIOS images.
- AMIBCP binaries.
- Intel FPT binaries.
- UEFITool binaries.
