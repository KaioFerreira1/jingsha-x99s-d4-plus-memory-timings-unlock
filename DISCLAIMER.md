# Disclaimer

This project is provided for research and educational purposes.

BIOS modification is risky. A wrong patch, incompatible firmware image, bad flash, power loss, or platform-specific firmware difference can brick the motherboard.

I am not responsible for bricked motherboards, data loss, corrupted firmware, unstable memory settings, or any damage caused by using this project.

You are responsible for:

- Dumping your own firmware.
- Verifying the patch applies to your exact firmware.
- Keeping a full SPI backup.
- Having a recovery method available.
- Understanding what you are flashing before you flash it.

The Git tree does not contain firmware images.

GitHub Releases provide experimental BIOS-region-only images for the exact tested target. They are not full SPI dumps and they are not universal BIOS images.

This project does not provide flashing tools.

No warranty is provided. Use at your own risk.
